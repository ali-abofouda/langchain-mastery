LangChain is a powerful open-source framework designed to simplify the creation of applications using large language models (LLMs).
It provides abstractions and tools for:
1. Document Loaders: Loading data from various sources such as text files, PDFs, websites, and databases.
2. Text Splitters: Splitting long documents into manageable chunks.
3. Embeddings & Vector Stores: Transforming text into vector representations and storing them for semantic search.
4. Chains & Agents: Connecting models with tools to make autonomous decisions.
