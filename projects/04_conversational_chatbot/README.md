# 💬 04 - Conversational Chatbot App

تطبيق محادثة تفاعلي ذكي يستند إلى **ChatGroq** و LangChain **`RunnableWithMessageHistory`** للتعامل مع الذاكرة الممتدة وسجل المحادثات مع إمكانية التنقل بين الجلسات والمسارات بـ Streamlit.

## 🚀 كيفية التشغيل

من المجلد الرئيسي للمشروع، قم بتشغيل الأمر التالي:
```bash
uv run streamlit run projects/04_conversational_chatbot/app.py
```

## 🌟 المميزات الرئيسية
- تذكر محادثات وأسماء المستخدمين في نفس الجلسة.
- إمكانية فتح جلسات جديدة أو تفريغ الذاكرة بضغطة زر.
- دعم كامل للغة العربية والإنجليزية والواجهة التفاعلية.
